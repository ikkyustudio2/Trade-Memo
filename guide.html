01

เปิดใช้งาน

ไม่ต้องติดตั้งโปรแกรม ไม่ต้องสมัครสมาชิก — เปิดลิงก์แล้วใช้ได้เลย

ลิงก์แอพ: ikkyustudio2.github.io/Trade-Memo

📱

มือถือ (iPhone)

  1. เปิดลิงก์ด้วย Safari
  2. กดปุ่ม แชร์ (สี่เหลี่ยมมีลูกศรชี้ขึ้น)
  3. เลือก เพิ่มไปยังหน้าจอโฮม
📱

มือถือ (Android)

  1. เปิดลิงก์ด้วย Chrome
  2. กดเมนู ⋮ มุมขวาบน
  3. เลือก เพิ่มไปยังหน้าจอหลัก
💻

คอมพิวเตอร์

  1. เปิดลิงก์ด้วย Chrome / Edge
  2. ปักหมุดแท็บ หรือเพิ่มเป็น Bookmark
  3. ใช้งานได้ทันทีไม่ต้องติดตั้ง

เปิดออฟไลน์ได้: หลังเปิดแอพครั้งแรกแล้ว จะจดบันทึกได้แม้ไม่มีเน็ต (ยกเว้นตอนอ่านภาพด้วย AI หรือซิงค์ Drive ที่ต้องต่อเน็ต)

02

หน้าตาแอพ

มี 3 หน้าหลัก สลับได้จากแถบด้านล่าง (มือถือ) หรือด้านบน (คอม)

📝

ไดอารี่

เลือกวัน → จดแผนก่อนเทรด → บันทึกออเดอร์ → สรุปหลังเทรด

📊

สรุปผล

winrate, กำไรขาดทุน, กราฟ, ปฏิทิน แยกราย วัน/สัปดาห์/เดือน/ปี

⚙️

ตั้งค่า

ธีม, สกุลเงิน, API key, Google Drive, สำรองข้อมูล

03

ตั้งค่าทั่วไป

ทำครั้งแรกที่เปิดแอพ ไม่บังคับ แต่แนะนำให้ตั้งไว้

เลือกธีม

หน้าตั้งค่า → ธีม เลือก ☀️ กลางวัน, 🌙 กลางคืน หรือตามระบบ — หรือกดไอคอนรูปพระอาทิตย์/พระจันทร์มุมขวาบนสลับเร็ว ๆ ได้เลย

ตั้งสกุลเงินบัญชี

หน้าตั้งค่า → สกุลเงินบัญชี ใส่ตามที่โบรกเกอร์ใช้ เช่น USDTHB จะโชว์ต่อท้ายตัวเลขกำไรในหน้าสรุปผล

04

อ่านภาพ MT5 ด้วย AI

ออปชันเสริม — แคปหน้าจอออเดอร์จาก MT5 แล้วให้แอพจดให้อัตโนมัติ ไม่ตั้งก็ใช้ตัวอ่าน OCR ฟรีในตัวแทนได้ (แม่นน้อยกว่า ต้องตรวจเลขเอง)

🤖

Claude (แม่นสุด)

  1. สมัคร key ที่ console.anthropic.com
  2. วางในหน้าตั้งค่า → Claude API key

จ่ายตามใช้จริง เฉลี่ยภาพละไม่กี่สตางค์

✨

Gemini (มี free tier)

  1. สมัคร key ฟรีที่ aistudio.google.com/apikey
  2. วางในหน้าตั้งค่า → Gemini API key

มีโควต้าใช้ฟรีต่อวัน เหมาะใช้ประจำ

Key เก็บที่ไหน: เก็บในเครื่อง/เบราว์เซอร์ของคุณเท่านั้น ไม่ถูกส่งไปที่ไหนนอกจาก Anthropic หรือ Google ตอนอ่านภาพจริง ๆ และไม่ถูกอัปโหลดขึ้น Google Drive ตอนซิงค์

05

ซิงค์ Google Drive

ออปชันเสริม — ใช้เก็บสำรองอัตโนมัติและซิงค์ข้อมูลข้ามเครื่อง แต่ละคนต้องสร้างของตัวเอง (ทำครั้งเดียว ใช้เวลาราว 5 นาที)

สร้างโปรเจกต์บน Google Cloud

ไปที่ console.cloud.google.com → กด New Project ตั้งชื่ออะไรก็ได้ เช่น Trade Memo

เปิดใช้ Google Drive API

เมนู APIs & Services → Library → ค้นหา Google Drive API → กด Enable

ตั้งค่าหน้ายินยอม (Branding)

เมนู Google Auth Platform → Branding → ใส่ App name และอีเมลตัวเอง 2 ช่อง (support email + developer contact) → Save

เพิ่มตัวเองเป็นผู้ใช้ทดสอบ

เมนู Audience → ส่วน Test users → กด Add users → ใส่อีเมล Gmail ของคุณ (แอพจะใช้ได้เฉพาะอีเมลที่เพิ่มไว้ตรงนี้ จนกว่าจะ Publish app)

สร้าง OAuth Client ID

เมนู Clients → Create client → Application type เลือก Web application

ที่ช่อง Authorized JavaScript origins ใส่ที่อยู่ที่คุณใช้เปิดแอพ:

เว็บที่แชร์ให้ใช้ https://ikkyustudio2.github.io

ถ้าเปิดจาก localhost บนคอมด้วย ให้เพิ่มอีกบรรทัด http://localhost:8765

เอา Client ID มาวางในแอพ

ก๊อป Client ID ที่ได้ (ลงท้ายด้วย .apps.googleusercontent.com) ไปวางที่หน้าตั้งค่า → Google Drive → OAuth Client ID แล้วกด ☁️ ซิงค์

ครั้งแรกที่กดซิงค์ Google อาจโชว์หน้าเตือน "Google hasn't verified this app" — เป็นเรื่องปกติเพราะยังไม่ได้ยื่นให้ Google ตรวจ กดที่ Advanced แล้วเลือก ไปที่ [ชื่อแอพ] (ไม่ปลอดภัย) เพื่อเข้าใช้ต่อได้ตามปกติ ปลอดภัยเพราะเป็นแอพของคุณเอง

ข้อมูลใครข้อมูลมัน: แต่ละคนล็อกอิน Google บัญชีตัวเอง ได้โฟลเดอร์ Drive แยกกันคนละก้อน ไม่ปนกับใคร

06

คำถามที่พบบ่อย

ไม่ตั้งค่าอะไรเลยใช้ได้ไหม

ได้เต็มที่ — เปิดลิงก์แล้วจดไดอารี่ บันทึกออเดอร์มือ ดูสรุปผลได้ทันที ส่วน AI อ่านภาพกับ Google Drive เป็นของเสริมเท่านั้น

ข้อมูลหายไหมถ้าไม่ได้ซิงค์ Drive

ข้อมูลอยู่ในเบราว์เซอร์เครื่องนั้น ถ้าล้าง cache/site data หรือลงเครื่องใหม่โดยไม่เคยซิงค์หรือดาวน์โหลดไฟล์สำรองไว้ก่อน จะกู้คืนไม่ได้ แนะนำอย่างน้อยกดดาวน์โหลดไฟล์สำรอง (หน้าตั้งค่า → สำรองข้อมูล) เป็นระยะ

ใช้เครื่องเดียวกันหลายคนได้ไหม

ได้ แต่ถ้าเปิดเบราว์เซอร์เดียวกันข้อมูลจะปนเป็นก้อนเดียว แนะนำให้แยกคนละ browser profile หรือแต่ละคนใช้เครื่องของตัวเอง

ต้องจ่ายเงินตรงไหนบ้าง

ตัวแอพและ Google Drive ฟรี 100% ส่วนอ่านภาพด้วย AI ถ้าเลือก Claude จะจ่ายตามใช้จริง (ถูกมาก) ถ้าเลือก Gemini มี free tier ให้ใช้ฟรี หรือข้ามไปใช้ OCR ในตัวก็ไม่เสียอะไรเลย

ลืม / ทำ API key หายทำไง

ลบของเดิมแล้วสมัครใหม่ที่เว็บผู้ให้บริการได้เลย ไม่กระทบข้อมูลไดอารี่ที่บันทึกไว้ แค่ต้องวาง key ใหม่ในหน้าตั้งค่าอีกครั้ง
